Project Overview

What the system was designed to do.

The project focused on a real-time multi-camera vision platform for smart-city monitoring. The system combined several computer vision tasks within one shared-backbone architecture, including object detection, tracking, semantic segmentation, classification, and face recognition.

My work covered system architecture, AI pipeline development, inference optimization, lightweight image preprocessing, and collaboration with software and UI engineers to integrate the computer vision pipeline into a complete product.

The Engineering Challenge

The project required more than running a single model on a single video.

Multiple Camera Streams

The system needed to process several real-time camera streams while supporting different computer vision tasks.

Memory Constraints

The AI pipeline had to remain stable in memory-constrained environments, especially when several models and streams were active.

Production Integration

The AI components had to connect with the software and user-interface layers of a complete smart-city product.

My Contribution

The main areas I designed and implemented.

  • Architected and developed HydraNet, a multi-process and multi-threaded shared-backbone computer vision system.
  • Developed vision pipelines for detection, tracking, segmentation, classification, and face recognition.
  • Optimized AI inference using ONNX, TensorRT, FP16 quantization, motion-triggered inference, and resolution scaling.
  • Developed lightweight image-processing methods to improve preprocessing quality, accuracy, and inference efficiency.
  • Collaborated with the software and UI teams to integrate the AI system into a complete product.

Technical Implementation

The main engineering decisions highlighted in the project.

Multi-Process and Multi-Threaded Design

The architecture separated camera acquisition and computer vision processing so that several streams and tasks could run efficiently.

Shared-Backbone Vision System

HydraNet used a shared-backbone approach to support several vision tasks within one system architecture.

Lightweight Preprocessing

Image-processing methods were used to improve input quality and reduce unnecessary computational load before model inference.

Product Integration

The AI pipeline was developed in coordination with software and UI teams so that model outputs could be used inside the complete application.

Deployment & Optimization

Methods used to improve inference efficiency and system stability.

ONNX & TensorRT

Models were prepared and optimized for efficient GPU inference in the production pipeline.

FP16 Quantization

Reduced-precision inference was used to lower memory and computational requirements.

Adaptive Inference

Motion-triggered inference and resolution scaling helped avoid unnecessary computation and balance processing speed with visual detail.
