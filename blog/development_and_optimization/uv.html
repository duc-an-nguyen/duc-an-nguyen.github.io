UV Notes

A practical reference for installing UV, creating Python environments, managing dependencies, synchronizing projects, and managing Python versions with either a pip style workflow or the native UV project workflow.

The source note separates UV usage into two approaches: a manual environment workflow similar to pip and venv, and the native UV project workflow that manages dependencies through pyproject.toml and uv.lock.

Install and update UV

Install UV

Terminal
curl -LsSf https://astral.sh/uv/install.sh | sh

Update UV

Terminal
uv self update

Two main ways to use UV

01

Manual environment workflow

Use UV in a way similar to pyenv, venv, virtualenv, and pip. Create an environment, activate it, then install packages manually.

02

Native UV project workflow

Initialize a UV project, store dependencies in pyproject.toml, maintain uv.lock, and use UV to run and sync the project.

Preferred workflow in the source note

The native UV project workflow is marked as the recommended approach.

Manual environment workflow

This workflow behaves similarly to the older combination of pyenv, venv, virtualenv, and pip.

Create an environment

Move into the project folder, then create a virtual environment with the required Python version.

Terminal
uv venv --python 3.11
Environment folder

The source note states that this creates a .venv folder inside the project.

Activate the environment

Terminal
source .venv/bin/activate

Install or remove packages with the pip interface

In this workflow, packages installed through uv pip are treated like direct pip operations.

Terminal
# Install or uninstall a package
uv pip install pandas
uv pip uninstall pandas

# Install packages from pyproject.toml
uv pip install -r pyproject.toml

requirements.txt workflow

Generate requirements.txt

Terminal
# Export directly from packages installed in the environment
uv pip freeze > requirements.txt

# Project has pyproject.toml and uv.lock
uv export -o requirements.txt --no-hashes

# Project has pyproject.toml only
uv pip compile pyproject.toml -o requirements.txt

Install or synchronize from requirements.txt

Terminal
# Add or update packages while keeping extra packages
uv pip install -r requirements.txt

# Make the environment match requirements.txt
uv pip sync requirements.txt
Difference in the source note

uv pip install -r keeps packages that are already present but not listed, while uv pip sync removes packages that are not required by the target file.

Native UV project workflow

Create a UV project

Terminal
# Initialize UV in the current folder
uv init

# Create a project with Python 3.11
uv init my_project --python 3.11

# Create a package with src layout
uv init --package my_project --python 3.11
Project layout

The source note marks the package style initialization with a src layout as recommended.

Add or remove dependencies

In the native UV workflow, dependencies are stored in pyproject.toml.

Terminal
uv add <package>
uv remove <package>

# Example
uv add pandas

Run and synchronize a UV project

Run code

Terminal
# Run normally
uv run python main.py

# Run with exact dependency synchronization
uv run --exact python main.py

The source note also mentions that the environment can be activated manually with source .venv/bin/activate and then used like a traditional Python environment.

Synchronize an existing project

Terminal
# Match the environment to uv.lock
uv sync

# Sync while keeping extra packages
uv sync --inexact

Other UV project commands

Create or refresh the lock file uv lock
Run a command in the project environment uv run
View the dependency tree uv tree
Build distribution archives uv build
Publish the project uv publish
uv lock

The source note suggests using it after manually editing pyproject.toml when you want to refresh the lock file without installing packages.

Manage Python versions with UV

Pin a Python version for the project

Terminal
uv python pin <python_version>

# Example
uv python pin 3.11
Project Python version

The source note uses this command to set or change the Python version associated with the current project.

Install or uninstall a Python version

Terminal
# Install a Python version
uv python install <python_version>

# Example
uv python install 3.11

# Uninstall a Python version
uv python uninstall <python_version>

List or find Python versions

Terminal
uv python list
uv python find <python_version>
