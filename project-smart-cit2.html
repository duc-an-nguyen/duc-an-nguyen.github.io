Computer vision case study

Real-Time Multi-Camera Smart City Vision System

A shared-backbone, multi-process and multi-threaded computer vision system developed for real-time multi-camera detection, tracking, segmentation, classification, and face recognition.

Role
AI Engineer – Computer Vision
Organization
Nova Intelligent Technology JSC
Period
Oct 2021 – Jan 2023
Project type
Production computer vision system

01

Project overview

The project focused on a real-time multi-camera computer vision platform for smart-city monitoring. Rather than running separate, isolated applications for every vision task, the system used a shared-backbone architecture to support several functions within one processing pipeline.

The system combined detection, tracking, semantic segmentation, classification, and face recognition. It was designed as part of a complete product, so the work also included coordination with software and user-interface teams during integration.

Portfolio message: this project demonstrates system architecture, real-time vision engineering, deployment optimization, and product integration—not only model training.

02

Engineering challenge

1

Multiple real-time streams

The pipeline had to process multiple camera sources while coordinating several computer vision tasks.

2

Memory constraints

The system needed stable inference in environments where GPU memory and computing resources were limited.

3

Production integration

Vision outputs had to connect with the wider software product and its user-interface workflow.

03

My contribution

  • Architected and developed HydraNet, a multi-process and multi-threaded shared-backbone computer vision system.
  • Developed real-time vision applications using YOLO-based models, DeepLabV3+, and tracking algorithms.
  • Implemented detection, tracking, segmentation, classification, and face-recognition capabilities.
  • Optimized the inference pipeline with ONNX, TensorRT, FP16 quantization, motion-triggered inference, and resolution scaling.
  • Developed lightweight image-processing methods to improve preprocessing quality and pipeline efficiency.
  • Collaborated with software and UI teams to integrate the AI system into a complete product.

04

System architecture

  • Multiple camera streams enter a coordinated acquisition and preprocessing pipeline.
  • A shared backbone reduces duplication across related vision tasks.
  • Task-specific components provide detection, segmentation, classification, face recognition, and tracking.
  • Structured outputs are passed to the wider software and UI product.

05

Technical implementation

A

Multi-process, multi-threaded execution

The system architecture coordinated camera acquisition and vision processing across concurrent execution paths to support real-time operation.

B

Shared-backbone design

HydraNet used shared feature extraction for multiple downstream computer vision functions instead of treating every task as an independent pipeline.

C

Applied vision models

The project used YOLO-based models, DeepLabV3+, and tracking algorithms for the required detection, segmentation, and temporal analysis tasks.

D

Lightweight preprocessing

Image-processing methods were developed to improve preprocessing quality, model accuracy, and pipeline efficiency without adding unnecessary overhead.

06

Deployment & optimization

The optimization work focused on maintaining stable performance in memory-constrained environments while preserving the functions needed by the product.

ONNX

Prepared trained models for a deployment-oriented inference workflow.

TensorRT

Optimized GPU inference for production deployment.

FP16 quantization

Reduced computational and memory requirements using half-precision inference.

Motion-triggered inference

Avoided unnecessary model execution when visual activity did not require it.

Resolution scaling

Balanced visual detail with inference efficiency and system stability.

Memory-aware pipeline design

Reduced pressure on constrained environments through architecture and runtime decisions.

07

Project outcomes

Unified vision pipeline

Supported several computer vision functions within one shared system architecture.

Stable constrained deployment

Improved inference efficiency and stability in memory-constrained environments.

Complete product integration

Connected the AI system with the software and user-interface components of the product.
